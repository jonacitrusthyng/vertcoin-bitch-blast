# Artwork

The dashboard uses Jona's supplied walnut/trailer scene, unmodified, in `src/Assets/walnut-trailer.jpg`. Plum, pink, green and walnut jokes carry its playful mood into the native WPF controls. `emi-host.png` is Jona's established adult Emi portrait. The 21 gallery images supplied with the original Emi project are used as song covers.

The edition's logo is the supplied Emi patch, with only the exterior white background removed using the built-in image-generation tool. The resulting transparent PNG is used in the sidebar and audio dock; a 256-pixel icon derived from it is embedded in the Windows executable. This is this community app's branding, not a claim that Vertcoin's official logo changed.

## Patch edit prompt

Edit target: the supplied circular embroidered Emi patch. Remove only the plain white background outside the circular patch, producing a clean transparent PNG cutout. Preserve the complete embroidery, circular border, EMI lettering, lemon motif, green eyes, character, clothing and prostheses exactly. Keep the full round patch with a small transparent margin. Do not redraw, add objects, alter colors, crop the patch, or add new text. This is the app logo.
